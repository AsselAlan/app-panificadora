# Carpeta del Backend (Supabase)

Esta carpeta contiene la configuración, los scripts SQL y las definiciones de la base de datos de Supabase.

## Contenido Recomendado:
- `schema.sql`: Script completo para la inicialización de tablas, triggers, restricciones y políticas RLS.
- Funciones RPC transaccionales (por ejemplo, `process_offline_sale`).
- Configuraciones de variables de entorno de Supabase.
